# Hi there, I'm Abdelrahman Hussien

🎓 **Computer Science Student | Software Engineer**

I’m a Computer Science student at Ain Shams University with a strong interest in **software engineering, Agentic AI, backend systems and data integration**.

I enjoy working on real-world systems where software goes beyond the application layer — from designing web platforms and APIs to working with databases, background services, system integrations, deployment, and automation.

- ⚙️ Recently have been working on [**1Alert**](https://github.com/ITExperts-From-Masr/one-alert), a configurable **Windows Services automation and data-integration framework** for synchronizing and processing data across different databases and systems.
- 🤖 Completed **AI Agent Developer Training**, working with LLMs, prompt engineering, LangChain, RAG, tool-using agents, and multi-agent systems.
- 🌍 Developed [**Sehetna**](https://sehetna.from-masr.com/), connecting environmental data with public health through map visualizations, interactive analytics, and AI-powered early warnings.
- 🛒 Developed [**Ontherack**](https://ontherack.from-masr.com/), an e-commerce platform for trips and books with an interactive administration and reporting system.
- 💻 Experienced with **full-stack applications, AI Automation, REST APIs, database systems, Windows Services, data synchronization, analytical dashboards**.
- 🤝 Open to **software engineering opportunities and collaborations** where I can contribute to real-world systems while continuing to grow technically.
